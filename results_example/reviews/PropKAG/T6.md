## 研究关注与研究议题分布
检索增强生成的研究版图首先覆盖检索侧组件与生成过程的协同衔接，其中查询改写、检索、重排序与融合等环节的优化策略既被单独考察，也被放入全流程中加以组合，体现出从单点改进到系统集成的层次差异（P001, P006）。在长上下文情境下，检索规模、粒度与噪声对生成质量的影响成为一类独立的适配议题，研究不仅关注检索数量，还追究分块大小和排序方式等细节如何改变输出可靠性（P005, P010）。生成结果对检索证据的忠实性及其评估方法构成质量保证层面的核心关注，涉及验证机制设计、评测基准构建以及自动评估器与人工判断的一致性校验（P003, P017）。基于图结构的检索增强工作流则将研究扩展到结构化知识利用领域，围绕图索引、图引导检索和图增强生成形成的完整流程被系统梳理，并延伸出对图构建质量与评估方法的专门讨论（P002, P024）。

检索侧协同研究在视角上呈现分化，部分工作从全流程角度审视各环节的组合策略，试图找到最优的衔接方式，另一部分则深入查询改写等单一机制，通过引入反馈信息或结构设计来提升该环节的贡献，前者着眼整体增益，后者追求局部突破（P007, P022）。长上下文RAG研究则明确将检索配置与生成质量挂钩，将检索规模扩大带来的硬负样本以及粒度选择、分块排序等噪声因素视为影响可靠性的关键边界，并进一步与直接长上下文处理进行成本与性能的权衡（P005, P010, P011）。由此可以认为，长上下文配置是检索协同在特定场景下的延伸，但它更强调参数权衡对生成结果的决定性作用，因而构成了一个相对独立的优化目标（P021）。

生成忠实性验证沿两条路线并进，机制上引入验证步骤、显式推理或上下文充分性分析来强化输出与证据的一致性，评测上则构建能力基准，系统考察模型在噪声鲁棒性、负拒绝、信息整合与反事实鲁棒性等维度上的表现，并关注真实世界检索上下文的利用差异（P015, P017, P030）。图结构增强检索工作流将图索引、图引导检索与图增强生成串成完整链条，图构建准确性、推理路径可解释性和答案完整性是突出关注的环节，评估子侧面则通过定制基准在噪声鲁棒性、信息整合与负面拒绝等场景中考验方案能力（P002, P024, P009）。

从已有证据看，检索侧协同与长上下文配置虽然同属检索环节，但前者强调组件间的交互设计与整体增益，后者强调场景参数对生成结果的因果影响，两者的优化对象和评价尺度都有清楚区分（P001, P005）。忠实性验证与图结构增强检索评估虽然共享鲁棒性、信息整合等能力要求，但落脚点分别指向证据忠实度和图推理支撑，前者更关注输出是否忠于检索内容，后者更关注图结构在复杂查询中的有效性，分化明确（P017, P009）。此外，部分研究尝试将多个环节纳入统一优化框架，体现出对跨环节耦合问题的关注，也暗示了未来整合不同关注面的可能方向（P028）。

## 核心研究问题
检索融合的系统分类是部分文献的核心问题，融合粒度被细分为粗、细与混合三类并伴随调度难题，另有工作从 token 级效应理论化融合的收益与损害（P001, P010, P044）。这一问题在图结构、多组件系统和形态丰富语言场景中分别转化为实体关系融合、多目标协调与流水线设计问题（P002, P028, P032）。在文档智能语境下，融合粒度进一步表现为上下文完整性与信息精确度之间的权衡，使同一分类问题面临不同的评价维度（P010）。评估环节的挑战贯穿上述分类与转移过程：基准不一致阻碍跨方法比较，读者模型对检索噪音的鲁棒性差异影响分类框架的验证（P042, P043）。

长上下文场景中检索段落增多导致生成质量下降，相关工作对瓶颈的定位存在分化，有的从训练无关与训练方法对比中寻找缓解，有的借助全局记忆降低对明确查询的依赖，还有的以历史响应构建图结构改善全局摘要（P005, P013, P014）。受控基准与系统评估将质量下降归因于模型能力短板与上下文利用不足，同时区分上下文不足与模型未能利用充分上下文两类错误（P011, P017, P030）。不完美检索引发的知识冲突则被单独视为后检索阶段的关键瓶颈，进一步将问题从检索端推向生成端（P034）。RAG 与长上下文被视为两种竞争策略，资源充足时长上下文模型平均性能更优而 RAG 成本显著更低，最优选择取决于模型能力、上下文长度、任务类型与检索特征的复杂交互，路由机制因此成为新的问题环节（P018, P021, P033）。在 RAG 内部，问题被拆解为链式验证、查询改写与协同训练等微观环节，分别针对生成与外部参考不一致、查询不精确以及检索器与生成器之间的结构差距（P015, P022, P031）。多模态与图结构场景进一步改变问题的对象：文档智能中的整体检索与推理涵盖文本、表格、图表与版面，GraphFlow 在文本丰富的知识图谱上关注准确且多样的知识获取，而真实世界上下文利用能力被单独提出并指出现有合成数据集可能高估该能力（P016, P020, P025）。

尽管已有大量研究，评估标准缺失与不同粒度调度机制不完善仍是尚未解决的环节，这些缺失直接限制跨方法比较与分类框架的可靠性（P010, P042, P044）。相关文献的根本分歧在于优化目标的主次排序，生成质量、成本与鲁棒性在不同工作中被赋予不同权重，目前仅达成 RAG 与长上下文各有所长、需条件化选择的共识，尚无统一最优解（P021, P033, P009）。

## 主要方法路径
组件构建与实证比较构成检索增强生成方法研究的互补路径，前者将查询改写、重排序和验证机制嵌入统一流程，后者在统一设置下比较策略的稳健表现（P003, P007, P040）。评估与组件优化形成方法回路，基准测试刻画任务场景差异，路由与查询改写等定向改进作用于检索环节，统一框架和诊断指标为复现与度量提供支撑（P017, P021, P035）。图结构增强检索将检索从文本匹配扩展为图关系建模，与标准检索增强生成在任务对象和推理方式上形成差异（P002, P009）。多模态检索增强与检索粒度分析从任务类型和检索单位角度拓展了研究边界（P010, P016）。

端到端框架将优化嵌入具体机制，包括组合神经查询改写、交叉编码器重排序与证据子声明验证，以多智能体强化学习建模检索与生成，以及检索增强生成与生成增强检索的迭代协同训练（P003, P028, P031）。统一设置下的经验比较显示，重排序、混合BM25和HyDE较稳健，而若干先进技术甚至可能使性能低于无检索增强生成基线（P040）。评估基准从不同角度服务问题定位，RGB、LaRA和土耳其语数据集分别覆盖能力、长上下文和跨语言场景（P017, P033, P032）。中文基准补充了创建、读取、更新、删除四类任务场景（P026）。与基准构建路线不同，路由与查询改写方法直接作用于检索环节（P021, P022）。RAGLAB与RAGChecker分别以统一框架和诊断指标支持算法复现与质量度量（P041, P035）。

长上下文研究将检索重排序与检索增强生成特定微调结合，或以全局记忆增强和KV压缩应对长序列，综述工作对此进行了系统梳理（P005, P013, P012）。图结构增强检索在鲁棒性评估中与标准检索增强生成形成对比，不同任务场景下表现存在差异（P009）。具体图增强方法中，GoR、GraphFlow和AGRAG分别以图边构建、流匹配和统计图建模，处理长上下文摘要、复杂查询和图构建可扩展性等不同问题（P014, P020, P024）。

多篇研究指出检索增强生成效果高度依赖任务与数据集特征，不存在适用于所有设置的单一策略（P007, P026, P040）。验证与反馈机制被共同强调为改进方向，但不同评估基准和指标之间的可比性仍有待检验（P003, P015, P035）。图结构增强方法多在特定基准下验证，其跨任务泛化能力、训练成本及在真实大规模知识图谱上的有效性仍需考察（P002, P014, P024）。真实世界查询下，检索增强生成的上下文利用能力可能被合成数据集高估，引导性弃权方法因此被用于减少幻觉（P011, P025, P030）。

## 研究发现与认识
多组证据相互支持，检索增强生成在知识密集型任务中确能借助外部知识提升准确性，但其收益以检索质量为前提：不完美检索不可避免且有害，内部知识与外部知识的冲突构成后检索阶段的关键瓶颈，检索段落增多时生成质量先升后降，硬负样本是主要诱因（P006, P034, P005）。与这一条件性图景一致，RAG 与长上下文模型的取舍同样由任务、模型与数据条件决定，资源充足时后者性能略高但成本更高，路由策略可在相近性能下大幅节省计算，不存在普遍最优方案（P021, P018, P033）。基于这些条件性认识，改进工作从单一模块优化转向流程级联合优化，MaFeRw 融合检索与生成反馈，MMOA-RAG 以多智能体强化学习联合优化检索与生成（P022, P028）。

GraphRAG 形成了包含索引、检索、精排与生成的标准化工作流，支持多跳关系推理，其定制化方法在 RGB 基准上表现鲁棒并能生成更可解释的推理路径（P002, P009）。在图结构增强之外，HawkRAG 以全局记忆、GoR 以图增强在长上下文任务上取得明显提升，显式理据生成优于 vanilla RAG，动态上下文学习与重排序可提升少样本性能（P013, P014, P003）。参数化 RAG 将外部知识集成到前馈网络以降低在线计算成本，并可与其他上下文 RAG 结合，体现了效率导向的互补路线（P038）。然而，改进并非总是增益：多领域多轮对话中重排序、混合 BM25 与 HyDE 一致优于 vanilla RAG，但若干高级技术无增益甚至低于 No-RAG，过度堆叠生成模块也会损害性能，简单查询澄清配合重排序反而是高性价比方案（P040, P032）。检索噪声的影响呈现双向性：噪声可按语言学特征区分为有益与有害两类，但受控实验中仍能显著降低较小 LLM 的 RAG 性能并诱发遗漏与幻觉（P037, P011）。LLM 在负拒绝、信息整合和反事实场景明显不足，知识图谱定制化检索可部分弥补这些短板，优于 RGB 基线（P017, P009）。

评估视角方面，合成数据集会夸大真实检索中的上下文利用能力，RAGChecker 与 MEMERAG 等细粒度诊断框架强调以人类判断对齐的忠实性和相关性评估，提示现有性能指标可能被高估（P025, P035, P036）。同时，系统性基准显示 RAG 对噪声注入和上下文冲突等对抗攻击十分脆弱，现有防御手段难以有效抵御；CRUD-RAG 与 LaRA 等基准进一步表明组件与场景的制约，当前证据多来自特定基准，跨语言迁移性尚未验证（P039, P026, P033）。在增量方向上，MINT 通过生成增强检索与检索增强生成的协同训练在 KILT 基准上优于主流基线，选择性生成则在上下文不充分时将回答正确率提升 2–10%（P031, P030）。然而，检索粒度上粗粒度检索易引入噪声、细粒度导致语义碎片化，混合粒度调度仍是挑战，多模态 RAG 在效率、细粒度表示与鲁棒性上也存在开放问题（P010, P016）。
